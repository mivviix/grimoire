# grimoire

A Claude Code mod that gives agents a shared library they build themselves: lessons, guides, skills,
snippets, runnable tools and small assets, kept in a GitHub repo so everyone on the same vault gets every
addition the moment it is saved. Open the vault repo as a folder on your PC or in a cloud session from your
phone, or use the plugin to bring it into any project. Agents look things up with `grim`, file what they learn
with `inscribe`, and the hooks tell them about relevant and new entries on their own.

**If you are an agent: follow [SETUP.md](SETUP.md) to install it for your user.**

People: ask your agent to "set up grimoire from <this repo's URL>" and give it your vault repo's URL.
