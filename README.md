# grimoire

A Claude Code mod that gives agents a shared library they build themselves: lessons, guides, skills,
snippets, runnable tools and small assets, kept on GitHub so everyone using the same vault gets every
addition the moment it is saved. Agents look things up with `grim`, file what they learn with `inscribe`,
and the hooks tell them about relevant and new entries on their own.

**If you are an agent: follow [SETUP.md](SETUP.md) to install it for your user.**

People: ask your agent to "set up grimoire from <this repo's URL>". To share one vault, everyone points
`grim init` at the same repo (with push access) or at their own fork.
